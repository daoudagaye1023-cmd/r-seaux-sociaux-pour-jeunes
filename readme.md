# 🌐 SocialJeunes

## 📱 Présentation

SocialJeunes est un site web de sensibilisation destiné aux jeunes
pour les aider à mieux comprendre les avantages et les dangers
des réseaux sociaux.

L'objectif est d'encourager un usage plus conscient, responsable
et sécurisé des réseaux sociaux.

## 🎯 Objectifs

- Comprendre les avantages des réseaux sociaux
- Identifier leurs principaux dangers
- Apprendre à protéger ses informations personnelles
- Adopter de bonnes habitudes numériques
- Apprendre à reconnaître certaines arnaques
- Sensibiliser au cyberharcèlement
- Vérifier les informations avant de les partager
- Tester ses connaissances avec un quiz interactif

## 📄 Pages du site

- Accueil

- Dangers
